# בתוקף

אפליקציה קטנה לניהול מלאי הפירות והירקות בבית. היא שואלת מדי פעם אם הפריטים עדיין בתוקף, וכשמשהו נגמר או מתקלקל היא שואלת אם להוסיף אותו לרשימת הקניות.

עצמאית לגמרי: HTML, CSS ו־JavaScript בלי build ובלי תלויות. היא לא קשורה לשאר הריפו.

## איך זה עובד

1. **מוסיפים מה שקניתם.** לחיצה על פריט מהקטלוג (כ־60 פירות, ירקות ועשבי תיבול) או הקלדת שם חופשי. לכל פריט יש הערכה התחלתית של כמה ימים הוא מחזיק, ושל המקום שבו שומרים אותו (מקרר, מחוץ למקרר, מקפיא).
2. **האפליקציה שואלת "עדיין בתוקף?"** השאלה הראשונה מגיעה באמצע זמן החיים המשוער. אפשר לענות:
   - **במצב טוב:** השאלה הבאה תגיע באמצע הזמן שנשאר, וכל יום כשמתקרבים לסוף.
   - **לאכול בקרוב:** הפריט מסומן ועולה לראש המלאי, והשאלה חוזרת מחר.
   - **סיימנו / זרקנו:** הפריט יוצא מהמלאי, והאפליקציה שואלת אם לקנות שוב.
   - **דלג:** השאלה חוזרת מחר.
3. **היא לומדת מהתשובות.** פריט שהתקלקל מקצר את ההערכה לפעם הבאה. פריט שעדיין טוב אחרי הזמן המשוער מאריך אותה. אם אותו פריט נזרק פעמיים בחודש, היא מציעה לקנות ממנו פחות. אם הוא נגמר מהר, היא מציעה לקנות יותר.
4. **רשימת קניות.** מסמנים מה נכנס לעגלה, ובסוף "קניתי" מעביר הכל למלאי עם התאריך של היום. אפשר להעתיק את הרשימה או לשלוח אותה בוואטסאפ. מתחת לרשימה מופיעים דברים שנגמרו לאחרונה ופירות שבעונה בישראל בחודש הנוכחי.

## הרצה

```bash
node groceries/serve.mjs
```

ואז לפתוח את http://127.0.0.1:5280. כדי לפתוח מהטלפון באותה רשת: `HOST=0.0.0.0 node groceries/serve.mjs`.

כל שרת סטטי מתאים, למשל GitHub Pages או Netlify. בכתובת https אפשר להתקין את האפליקציה למסך הבית: בכרום "התקנת אפליקציה", ובספארי "שיתוף ← הוספה למסך הבית". אחרי ההתקנה היא נפתחת גם בלי אינטרנט.

## תזכורות

האפליקציה שואלת כשפותחים אותה. כדי לזכור לפתוח אותה, בהגדרות אפשר לקבוע שעה ולהוסיף תזכורת יומית ל־Google Calendar או לקבל קובץ יומן (‎.ics) ל־iPhone.

התראות דפדפן עובדות כשהאפליקציה פתוחה ברקע או מותקנת במסך הבית. התראת push אמיתית, כשהאפליקציה סגורה לגמרי, דורשת שרת, ואין כזה כאן.

## איפה הנתונים נשמרים

בדפדפן, ב־`localStorage`. אין חשבון, ושום דבר לא נשלח לשום מקום. לכן כדאי מדי פעם ללחוץ על "העתקת גיבוי" בהגדרות ולשמור את הטקסט. "שחזור מגיבוי" מחזיר אותו.

כשהאפליקציה פתוחה כ־Artifact ב־claude.ai, הנתונים נשמרים גם במסד הנתונים של ה־Artifact, בתיקייה פרטית של כל משתמש, ומסתנכרנים בין מכשירים. הקוד לזה נמצא ב־`storage.js`.

## קבצים

| קובץ | מה יש בו |
| --- | --- |
| `index.html` | הדף |
| `app.js` | הממשק: מסכים, כפתורים, תזכורות |
| `logic.js` | כל ההחלטות: תאריכים, מתי לשאול, למידה, רשימת קניות, סטטיסטיקה, ניסוח בעברית. בלי DOM, נבדק בנפרד |
| `catalog.js` | הקטלוג, ההערכות ההתחלתיות ועונות הפירות |
| `storage.js` | שמירה בדפדפן, וסנכרון כשרצים בתוך claude.ai |
| `styles.css` | העיצוב, כולל מצב כהה |
| `sw.js`, `manifest.webmanifest`, `icon*` | התקנה למסך הבית ועבודה בלי אינטרנט |
| `serve.mjs` | שרת קטן להרצה מקומית |
