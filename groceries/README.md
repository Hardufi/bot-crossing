# בתוקף

אפליקציה קטנה לניהול מלאי הפירות, הירקות והבשר בבית. היא שואלת מדי פעם אם הפריטים עדיין בתוקף, כמה הם עלו ואיפה נקנו, וכשמשהו נגמר או מתקלקל היא שואלת אם להוסיף אותו לרשימת הקניות.

עצמאית לגמרי: HTML, CSS ו־JavaScript בלי build ובלי תלויות. היא לא קשורה לשאר הריפו.

## איך זה עובד

1. **מוסיפים מה שקניתם.** לחיצה על פריט מהקטלוג (כ־60 פירות, ירקות ועשבי תיבול, וכ־25 סוגי בשר ודגים: עוף, הודו, בקר, כבש, דגים, נקניקים ומעושנים) או הקלדת שם חופשי. לכל פריט יש הערכה התחלתית של כמה ימים הוא מחזיק, ושל המקום שבו שומרים אותו (מקרר, מחוץ למקרר, מקפיא). בשר טרי מחזיק במקרר יום־יומיים, ולכן אפשר לסמן "ישר למקפיא" כבר בהוספה; בשר שהופשר מקבל שוב יום־יומיים.
2. **האפליקציה שואלת "עדיין בתוקף?"** השאלה הראשונה מגיעה באמצע זמן החיים המשוער. אפשר לענות:
   - **במצב טוב:** השאלה הבאה תגיע באמצע הזמן שנשאר, וכל יום כשמתקרבים לסוף.
   - **לאכול בקרוב:** הפריט מסומן ועולה לראש המלאי, והשאלה חוזרת מחר.
   - **סיימנו / זרקנו:** הפריט יוצא מהמלאי, והאפליקציה שואלת אם לקנות שוב.
   - **דלג:** השאלה חוזרת מחר.
3. **היא לומדת מהתשובות.** פריט שהתקלקל מקצר את ההערכה לפעם הבאה. פריט שעדיין טוב אחרי הזמן המשוער מאריך אותה. אם אותו פריט נזרק פעמיים בחודש, היא מציעה לקנות ממנו פחות. אם הוא נגמר מהר, היא מציעה לקנות יותר.
4. **איפה ובכמה.** אחרי קנייה האפליקציה שואלת איפה קניתם וכמה עלה כל פריט (לק״ג או ליחידה), פעם אחת, בזמן שהקבלה עוד בזיכרון. היא שומרת את המחיר האחרון בכל חנות ומראה אם התייקר או הוזל. בלשונית "מחירים" רואים לכל מוצר את המחיר בכל חנות ואת הזולה ביותר, ושם גם מנהלים את רשימת החנויות. ברשימת הקניות מופיע ליד כל פריט איפה הוא הכי זול, ואיזו חנות הכי משתלמת לכל הרשימה.
5. **עדכון מהיר בסרטון.** מצלמים סרטון קצר של הקניות (או בוחרים סרטון או תמונות), והאפליקציה מוציאה ממנו כמה תמונות, שולחת אותן ל־Claude ומקבלת רשימה של מה שזוהה. על כל פריט היא שואלת "זיהיתי נכון?" עם כן ולא, ובסוף מוסיפה למלאי רק את מה שאושר, ועוברת לשאלה איפה קניתם ובכמה. אם לא הכל נכנס לסרטון אחד, "צילום נוסף" שומר את מה שכבר אושר ומחבר את הכמויות. הסרטון עצמו לא יוצא מהמכשיר, רק התמונות שנבחרו ממנו.
6. **רשימת קניות.** מסמנים מה נכנס לעגלה, ובסוף "קניתי" מעביר הכל למלאי עם התאריך של היום. אפשר להעתיק את הרשימה או לשלוח אותה בוואטסאפ. מתחת לרשימה מופיעים דברים שנגמרו לאחרונה ופירות שבעונה בישראל בחודש הנוכחי.

## הרצה

```bash
node groceries/serve.mjs
```

ואז לפתוח את http://127.0.0.1:5280. כדי לפתוח מהטלפון באותה רשת: `HOST=0.0.0.0 node groceries/serve.mjs`.

כל שרת סטטי מתאים, למשל GitHub Pages או Netlify. בכתובת https אפשר להתקין את האפליקציה למסך הבית: בכרום "התקנת אפליקציה", ובספארי "שיתוף ← הוספה למסך הבית". אחרי ההתקנה היא נפתחת גם בלי אינטרנט.

## תזכורות

האפליקציה שואלת כשפותחים אותה. כדי לזכור לפתוח אותה, בהגדרות אפשר לקבוע שעה ולהוסיף תזכורת יומית ל־Google Calendar או לקבל קובץ יומן (‎.ics) ל־iPhone.

התראות דפדפן עובדות כשהאפליקציה פתוחה ברקע או מותקנת במסך הבית. התראת push אמיתית, כשהאפליקציה סגורה לגמרי, דורשת שרת, ואין כזה כאן.

## זיהוי בסרטון: איך זה מגיע ל־Claude

- **בתוך claude.ai** (כ־Artifact): דרך היכולת `sample`, מהחשבון של מי שמשתמש בדף. בפעם הראשונה הדף מבקש אישור.
- **בכל מקום אחר**: דרך ה־API של Anthropic, עם מפתח API משלכם שמזינים בהגדרות. המפתח נשמר רק בדפדפן הזה (לא בגיבוי ולא בסנכרון) ונשלח רק ל־Anthropic. הבקשה משתמשת ב־SDK הרשמי (`@anthropic-ai/sdk`, נטען מ־jsDelivr), במודל `claude-opus-5-5`, בפלט JSON לפי סכמה, ובמעבר אוטומטי למודל אחר אם הבקשה נדחית (`fallbacks: "default"`). כל זיהוי נרשם כשימוש בחשבון ה־API שלכם.

## איפה הנתונים נשמרים

בדפדפן, ב־`localStorage`. אין חשבון, ושום דבר לא נשלח לשום מקום. לכן כדאי מדי פעם ללחוץ על "העתקת גיבוי" בהגדרות ולשמור את הטקסט. "שחזור מגיבוי" מחזיר אותו.

כשהאפליקציה פתוחה כ־Artifact ב־claude.ai, הנתונים נשמרים גם במסד הנתונים של ה־Artifact, בתיקייה פרטית של כל משתמש, ומסתנכרנים בין מכשירים. הקוד לזה נמצא ב־`storage.js`.

## קבצים

| קובץ | מה יש בו |
| --- | --- |
| `index.html` | הדף |
| `app.js` | הממשק: מסכים, כפתורים, תזכורות |
| `logic.js` | כל ההחלטות: תאריכים, מתי לשאול, למידה, רשימת קניות, סטטיסטיקה, ניסוח בעברית. בלי DOM, נבדק בנפרד |
| `catalog.js` | הקטלוג, ההערכות ההתחלתיות ועונות הפירות |
| `storage.js` | שמירה בדפדפן, וסנכרון כשרצים בתוך claude.ai |
| `frames.js` | הוצאת תמונות מסרטון (או מתמונות) בתוך הדפדפן |
| `vision.js` | הזיהוי: ההנחיה ל־Claude, סכמת התשובה, ניקוי התוצאות, ושתי הדרכים להגיע ל־Claude |
| `styles.css` | העיצוב, כולל מצב כהה |
| `sw.js`, `manifest.webmanifest`, `icon*` | התקנה למסך הבית ועבודה בלי אינטרנט |
| `serve.mjs` | שרת קטן להרצה מקומית |
